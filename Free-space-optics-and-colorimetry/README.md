A modular Python framework for modeling **free-space illumination architectures, laser-phosphor light engines, colorimetry, and automated optical test data processing**. Designed for solid-state projection platforms, DMD/DLP light engines, color gamut evaluation (Rec. 709 / DCI-P3), and automated spectrometer/colorimeter log parsing.

---

## 📌 Overview & Architecture

Modern high-brightness projection platforms utilize solid-state light sources (blue lasers, yellow phosphor wheels, and red LEDs/lasers) combined with Digital Micromirror Devices (DMD/DLP). Achieving target image brightness, color accuracy, and illumination uniformity requires close integration between optical simulation, color science, and automated lab testing.

```
[Module 1: Colorimetry Engine]      ---> Laser/Phosphor Spectral Mixing & Gamut Analysis
[Module 2: Spectrometer Pipeline]   ---> Automated Parsing & Thermal Drift Analysis of CSV Logs
[Module 3: Free-Space Ray Optics]   ---> Ray Tracing & Monte Carlo Tolerancing onto DMD Planes
```

## 🛠️ Repository Modules

### 1. `01_colorimetry_light_engine/` — Laser-Phosphor Color Synthesis & Gamut Evaluation
* **Objective**: Compute system-level colorimetry, CIE chromaticity, and luminous flux for solid-state light engines.
* **Key Features**:
  * Models Spectral Power Distributions (SPDs) for blue laser diodes (455 nm), yellow broad-band Ce:YAG phosphor emission, and red laser/LED sources.
  * Calculates **CIE 1931 Tristimulus Values ($X, Y, Z$)** and **Chromaticity Coordinates ($x, y$)**.
  * Determines color gamut area overlap against industry display standards (**Rec. 709**, **DCI-P3**, and **Rec. 2020**).
  * Evaluates dichroic filter transmission and color balance efficiency.

### 2. `02_spectrometer_data_pipeline/` — Automated Optical Test Data Processing
* **Objective**: Process raw spectral and colorimetric measurement logs from laboratory hardware.
* **Key Features**:
  * Parses unstructured CSV log files generated by lab spectrometers and colorimeters.
  * Extracts peak wavelength, Full-Width at Half-Maximum (FWHM), and spectral shifts over operating temperature runs (20 °C to 70 °C).
  * Computes 2D illuminance/luminance uniformity maps and screen center-to-corner fall-off metrics.
  * Generates automated summary plots and publication-ready spectral figures.

### 3. `03_free_space_ray_tracing/` — Illumination Optics & Tolerancing
* **Objective**: Model free-space light delivery through homogenizers onto a DMD micro-mirror target.
* **Key Features**:
  * Implements 2D paraxial ABCD matrix and vector ray tracing from laser diode sources, collimating doublets, and fly-eye integrators / rod homogenizers.
  * Maps spatial flux density and numerical aperture (NA) matching at the DMD micro-array active area.
  * Executes **Monte Carlo tolerance sweeps** for element tilt (± 0.5°), decenter (± 50 µm), and thermal expansion to assess illumination uniformity degradation and stray light risk.
